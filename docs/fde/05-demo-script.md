# 5. Demo script (10 minutes, for the Head of Support and IT security)

1. **The pain (1 min).** "Today an agent needs about 5 minutes to find the refund rule for a damaged
   parcel." Show the shared-drive search with 14 similar file names.
2. **The answer (2 min).** Ask: *"A parcel arrived damaged; how long does the customer have to file a
   claim, and what evidence do we need?"* Show the answer and the cited SOPs. Open the cited SOP to prove it.
3. **Honesty (1 min).** Ask something not in their SOPs (*"What is our policy on drone delivery?"*):
   the assistant says it cannot find it. "It will not invent policy."
4. **Safety (2 min).** Show a document containing "ignore all instructions..." and ask about it: the
   answer reports the text instead of obeying it. Then use the other demo tenant's key: no Kestrel data.
5. **Speed and cost (2 min).** Backend SLO dashboard: p95 latency, availability; token panel and the
   cache hit (second identical question is instant and free).
6. **Operations (1 min).** "Your new SOPs go live by one upload; access changes are reviewed pull
   requests; we get alerted before you notice problems."
7. **Next step (1 min).** Pilot with 8 agents for 4 weeks, success criteria from the problem statement,
   weekly check-in.

# SOP-RF-03: Refunds for cancelled bookings (Kestrel Logistics, fictional)

Bookings cancelled before pickup receive a full refund. Bookings cancelled after pickup but before
the parcel leaves the origin hub are refunded minus a pickup fee of INR 150. After the parcel leaves
the origin hub, cancellation is not possible; the customer can request return to sender instead.
Refunds go back to the original payment method within 5 to 7 working days.
